# LOST: The Missing Island — חלק 1: ההתרסקות · חלק 2: האות · חלק 3: המתבונן · מחנה הבסיס

משחק הישרדות ומסתורין בתלת־ממד, רץ בדפדפן במחשב. נבנה עם **Three.js** ו־**Vite** (JavaScript).
כל המודלים נבנו מגאומטריה בקוד, הטקסטורות מצוירות ב־canvas והסאונד מסונתז ב־Web Audio — אין נכסים חיצוניים.

## הרצה מקומית

דרוש Node.js 18 ומעלה.

```bash
npm install
npm run dev        # http://localhost:5173
```

### בנייה ובדיקת גרסת הפרסום

```bash
npm run build      # יוצר את dist/
npm run preview    # מריץ את dist/ על http://localhost:4173
```

## פרסום ב-Netlify

- **גרירה:** `npm run build` ואז לגרור את התיקייה `dist` אל https://app.netlify.com/drop
- **מ-Git:** לחבר את הריפו ב-Netlify. `netlify.toml` כבר מגדיר `npm run build` ו-`dist`.

## גרסה למחשב (Windows)

אפשר להוריד את המשחק ולהתקין אותו כמו כל משחק רגיל:
https://github.com/amitshabatgoltz-create/lost-island/releases/latest

- `LOST-Setup.exe` מתקין את המשחק ושם אייקון על שולחן העבודה.
- `LOST-Portable.exe` מריץ את המשחק בלי התקנה.
- בפעם הראשונה Windows עלול להציג מסך כחול "Windows protected your PC": ללחוץ "More info" ואז "Run anyway".
- הגרסה המותקנת (Setup) מתעדכנת לבד: בכל פתיחה היא בודקת אם יש גרסה חדשה, מורידה אותה ברקע ושואלת אם להפעיל מחדש. הגרסה הניידת (Portable) לא מתעדכנת לבד.
- המשחק נפתח במסך מלא. F11 או Alt+Enter עוברים בין מסך מלא לחלון.

**עדכונים:** הגרסה המותקנת לא מתעדכנת לבד. אחרי כל עדכון של המשחק מורידים שוב את `LOST-Setup.exe` מאותו קישור ומתקינים מעל; השמירות והדמות שבחרת נשמרות (הן בתיקיית המשתמש של Windows, לא בתיקיית ההתקנה).

הקובץ נבנה אוטומטית ב-GitHub Actions (`.github/workflows/desktop.yml`) בכל עדכון של `main`. הקוד של האפליקציה נמצא ב-`desktop/` (Electron). להרצה מקומית: `npm run build`, להעתיק את `dist` אל `desktop/app`, ואז בתוך `desktop/` להריץ `npm install`, `npx install-electron` ו-`npm start`.

## גרסאות ל-Poki ול-CrazyGames

`npm run build:poki` בונה את המשחק עם ה-SDK של Poki לתיקייה `dist-poki`, ו-`npm run build:crazygames` בונה אותו עם ה-SDK של CrazyGames לתיקייה `dist-crazygames`.
בכל עדכון של `main` נבנים אוטומטית (`.github/workflows/portals.yml`):
- `LOST-poki.zip` בדף https://github.com/amitshabatgoltz-create/lost-island/releases/tag/poki-latest (מעלים ב-developers.poki.com)
- `LOST-crazygames.zip` בדף https://github.com/amitshabatgoltz-create/lost-island/releases/tag/crazygames-latest (מעלים ב-developer.crazygames.com)

- `src/portal.js` מדבר עם ה-SDK של האתר: מודיע מתי הטעינה נגמרה, מתי משחקים ומתי לא (לובי, הפסקה, סוף פרק), ומציג פרסומת קצרה רק ברגעים טבעיים: כשלוחצים "Play" בלובי וכשממשיכים לחלק הבא. בזמן הפרסומת הצליל מושתק.
- בכל גרסה אחרת (האתר, המחשב) אין SDK, וכל הקריאות האלה לא עושות כלום.
- הגופנים ארוזים בתוך המשחק (`@fontsource`) ולא נטענים מגוגל, כדי שהמשחק לא יפנה לאתרים אחרים.

## לובי ובחירת דמות

המשחק נפתח בלובי על החוף: הדמות שלך עומדת על החול, שברי המטוס והג׳ונגל ברקע.
בכניסה הראשונה בוחרים אחת מ־8 דמויות (Mixamo): אלכס, נועה, מרקוס, שרה, דניאל, יוני, מאיה ורמי.
הבחירה נשמרת בהגדרות (`skin`) ואפשר להחליף אותה בכל זמן ב"החלף דמות" — היא לא נוגעת בהתקדמות.
מי ששיחק לפני העדכון מקבל את אלכס (הדמות המקורית) כבחירה מסומנת מראש.
"שחק" ממשיך מהשמירה אם יש כזו, ואחרת מתחיל מהפתיחה במטוס; "משחק חדש" מוחק את השמירה (אחרי אישור).
כל הדמויות משתמשות באותן אנימציות (מ־`survivor.glb`), מותאמות לגובה של כל אחת.
כשמתחילים ללכת מעמידה, הדמות עושה את הצעדים הראשונים באנימציית Start Walking (מ־`public/models/anims/`), בקצב של התנועה כדי שהרגליים לא יחליקו, ואז ממשיכה להליכה הרגילה. הוספת אנימציה: `tools/anims/README.md`.

### גרפיקה

```
src/gfx/textures.js         טקסטורות פרוצדורליות שחוזרות על עצמן (חול, דשא, אדמה, סלע, עלים, קליפה, פח מטוס) + מפות נורמל
src/gfx/materials.js        שיידר קרקע עם 4 שכבות מעורבבות לפי גובה, טקסטורה טריפלנרית לסלעים, עלווה עם רוח ואור עובר
src/gfx/post.js             עיבוד תמונה: MSAA, זוהר עדין, תיקון צבע וויניטה
src/gfx/perf.js             איכות אוטומטית לפי קצב הפריימים + הסתרת צמחייה שנבלעת בערפל
```

בהגדרות יש "גרפיקה מתקדמת": כשהיא כבויה אין עיבוד תמונה, הקרקע פשוטה יותר והצללים ברזולוציה נמוכה — למחשבים חלשים. `?lowfx` בכתובת מכבה אותה בכוח.

"התאמת איכות אוטומטית" (פועלת כברירת מחדל) מודדת את קצב הפריימים בזמן המשחק. אם המשחק נתקע היא מורידה בשלבים רזולוציה, החלקת קצוות, צללים ואפקטים, ואם יש מקום היא מעלה בחזרה. השלב שנבחר נשמר להפעלה הבאה. `?fps` בכתובת מציג את הקצב, את השלב ואת מספר הציורים בפריים.

## חלק 2 — האות

- מעבר מהחוף ליער בשביל הצפוני שמאחורי זנב המטוס (והליכה חזרה לחוף בקצה הדרומי של היער).
- יער לילה: גבעות, נחל עם גשר עצים, רכס מזרחי תלול עם עלייה אחת, קרחות, שורשים, גזעים שנפלו, ערפל, ירח וצמחייה זזה.
- 9 משימות: כניסה ליער · מעקב אחרי האות האדום · מציאת תא כוח · הפעלת המשדר · חקירת המחנה (אוהל, בקתה, שולחן) · קוד הארגז הנעול · איסוף מסמכי המחקר · נקודת התצפית על הרכס · חזרה אל המשדר.
- 7 רשומות חדשות בחוברת, מפת יער שמתמלאת לפי מה שהשחקן גילה, וכל רמזי חלק 1 נשמרים.
- מתח: רעשים רחוקים בצלילים מרחביים, דמות שחולפת בין העצים, מכשיר קשר שנדלק לבד, אורות מהבהבים במחנה, עקבות שמובילות אל קצה צוק, ומפגש קצר בלי לקחת את השליטה מהשחקן.
- סיום: שידור, האות האדום עובר למקום אחר, אורות נדלקים ביער בזה אחר זה, והרשומה “Someone is still here.”

## חלק 3 — המתבונן

- ממשיך ישר מסוף חלק 2: אחרי הסיום נפתח ביער שביל צפון־מזרחי (אחרי המחנה) אל **הרכס הצפוני**.
- כרטיס פתיחה “CHAPTER 3 / THE OBSERVER” והמטרה “Follow the northbound signal”.
- הרכס: עמק לילי צר, כבל פגוע שמוביל צפונה, עקבות, פנסים מהבהבים, מחנה ברזנט עם מקליט שטח, מצלמת שביל שמסתובבת אחרי השחקן, ארגז חלקי חילוף, דף מפה קרוע ודלת פלדה בתוך הצוק.
- **החזרת החשמל:** נתיך ראשי מהארגז אל הגנרטור, חיווט תיבת החיבורים לפי שלושה כללים (אותו מנגנון חיווט של חלק 2), התנעת הגנרטור, ואז העברת תג הגישה בפאנל. צלילים: קליק, זמזום, התנעה, נעילות ודלת כבדה.
- **המתקן N-1:** מסדרון כניסה, עמדת ביטחון (שולחן, מסוף, לוקרים, מצלמה, דלת חסומה), חדר תצפית (קיר מסכים קריאים, שולחן מרכזי, מקליט סלילים, מפה, לוח עם חוטים אדומים), ארכיון (ארונות, ארון אדום נעול, מסוף) וחדר בקרה (לוח חשמל, מסוף נעול, מכשיר השמעה).
- 5 מסמכים חדשים בחוברת (מזכר NIGHTJAR, דוח סיווג נוסעים, תיק 31A, אי־התאמות בכוח אדם, פתק של N.) ועוד ממצאים: מקליט השטח, דף המפה, ההקלטה המוגבלת ו-PHASE 3.
- **קוד הארכיון** (DDHHMM): היום שבו הגענו + השעה שבה נפתח “חלון התצפית”. הכול כבר נמצא בחוברת: לוח השנה מהבקתה ודוח הנוסעים.
- **ההקלטה:** נקטעת באמצע, והשאר נמצא ב“קלט משני” — מכשיר הזיכרון מחלק 1 (CACHE / TAIL).
- **הפסקת חשמל:** האורות כבים, תאורת חירום אדומה, הפנס ממשיך לעבוד, ומסך גיבוי מציג שידור חי (render target) של חדר התצפית — כולל השחקן עצמו. האירוע לא חוזר, ואם סוגרים את המשחק באמצע הוא ממשיך בטעינה הבאה.
- **סיום:** “NIGHTJAR SYSTEM / SUBJECT 31A / OBSERVATION ACTIVE”, ההודעה “If you can hear this, they've already found you.”, רעש מכני רחוק, דפיקות מאחורי הדלת החסומה, המסך כבה, וכרטיס “CHAPTER 3 COMPLETE / THE OBSERVER” עם “NIGHTJAR PROTOCOL — PHASE 3 ACTIVATED”. חלק 4 לא נפתח אוטומטית.
- שמירות: שמירות מחלקים 1–2 נטענות כרגיל, משחק חדש מתחיל בהתרסקות. מי שסיים את חלק 2 ממשיך ישר לחלק 3.

## חידות ביער (חלק 2)

ביער אין מצפן. מנווטים לפי האור האדום מעל הצמרות, לפי השבילים והעקבות, ולפי מפת היער בחוברת. כשנתקעים, H נותן רמז מדורג.

- **מנעול הסמלים** על ארגז האספקה: שלושה סימנים חרוטים על עצים לאורך העקבות מהמשדר. מספר החריצים מתחת לכל סימן הוא הסדר.
- **חיווט המשדר:** ארבעה חוטים לארבעה מסופים, לפי שלושה כללים בכרטיס השירות שבארגז. יש פתרון אחד בלבד.
- **כוונון התדר:** שום מספר לא כתוב. מקשיבים לרעש ועוקבים אחרי מד האות עד שהתחנה ננעלת.
- **קוד הארגז הנעול:** השלט אומר APPROVAL / ARRIVAL. לוח השנה בבקתה והמסמך מחלק 1 משלימים את התשובה.
- **המשקפת במחנה:** סורקים את היער בזום ומחפשים נצנוץ עדשה על הרכס. הדרך השנייה היא לעקוב אחרי העקבות הטריות.

כל הפתרונות נמצאים ב-`src/data/puzzles.js`, והרמזים בתוך `src/data/quests.js`.

## בהירות המשחק

- **המטרה:** הפאנל בפינה מציג משפט אחד שמסביר מה מחפשים עכשיו בסיפור. המשפט מתחלף רק אחרי האירוע המתאים: ההתרסקות, הגילוי שמישהו ידע עליה מראש, או האות האדום.
- **החקירה (J):** העמוד הראשון בחוברת. בצד אחד המטרה, המשימה הנוכחית, למה זה חשוב, ומה כבר עשית. בצד השני מה אני יודע ומה עוד צריך לגלות. הכול נבנה מהמצב האמיתי של השמירה ולא חושף דברים שעוד לא התגלו.
- **רמז חדש:** כשמוצאים רמז מופיע כרטיס שמסביר מה למדת ושהרמז נרשם בחוברת.
- **הדרכה חד־פעמית:** בפעם הראשונה שנתקלים במנגנון מופיעה שורת הסבר קצרה, למשל ל-E, ל-J, לפנס, לארגז נעול, ליער או לתיבה. אחרי שהיא הופיעה היא לא חוזרת, וזה נשמר בהגדרות.
- **רמזים (H):** אופציונליים ולא נפתחים לבד. רמה 1 מכוונת לפרט שכדאי לבדוק, רמה 2 אומרת אילו רמזים להשוות, ורק ברמה 3 מוסבר ההיגיון ומגיעים לפתרון.
- **אין חץ ואין מרחק:** הניווט נעשה לפי ציוני דרך, מפות ורמזים בחוברת.
- הקבצים הרלוונטיים: `src/data/story.js` (מטרות ותוכן עמוד החקירה), `src/data/quests.js` (רמזים), `src/ui.js`.

## מחנה הבסיס ואחסון

- מחסה על החוף, מערבית לאזור ההתעוררות: גג ברזנט, דופן מגוף המטוס, תיבת עץ, שולחן עבודה, לוח ראיות, פנס תלוי, מדורה וציוד.
- **תיבה (E):** שני צדדים — התיק (6 מקומות) והתיבה (16 מקומות). לחיצה על ערימה מעבירה אותה כולה, Shift+לחיצה או קליק ימני מעבירים פריט אחד, ויש כפתור “כל המשאבים לתיבה”. פריטים זהים נערמים. כשאין מקום מופיעה הודעה. E או Esc סוגרים.
- **משאבים:** שאריות עץ, חבל, בד, סוללות ורכיבים אלקטרוניים — 15 ערימות בחוף וביער. כשהתיק מלא, הערימה נשארת במקומה.
- **פריטי מפתח** (פנס, חוברת, תא כוח) תמיד נשארים אצל השחקן ולא תופסים מקום בתיק, כדי שתיק מלא לא יחסום את הסיפור.
- **שולחן עבודה:** מציג את החומרים שיש בתיק ובתיבה. שרטוטים עדיין לא קיימים.
- **לוח ראיות:** דף נעוץ לכל רשומה בחוברת; E פותח את החוברת על הרמזים.
- **שמירה:** התיק, התיבה, הפנס והמחסה נשמרים. שמירות ישנות מומרות אוטומטית (מים ותחבושת שנאספו עוברים לתיק) בלי לאפס התקדמות.
